# Third-party sources

- `pylitho/`, `pyilt/`, `pycommon/`, and `lithobench/` are adapted
  from the existing LithoGRPO experiments and the MIT-licensed
  [LithoBench](https://github.com/shelljane/lithobench) implementation.
  The original copyright and license are reproduced in
  `third_party/licenses/LithoBench.txt`.
- `adabox/` retains its existing adaptive-boxes license and notices.
- The MiniUnet/flow-matching experiments build on the educational implementation
  credited to Tong Tong in the original project README
  ([author's page](https://space.bilibili.com/323109608)). The stage-2 parameter
  names and model computations are preserved here.

Benchmark layouts, pretrained model weights, and lithography kernel assets are
external inputs and are not included in this code release. Consult the upstream
project and dataset terms when obtaining those assets.
